# Herunterladen der ISO-Datei
Die Software für den Lernstick wird als [ISO-Abbild](https://de.wikipedia.org/wiki/ISO-Abbild) zur Verfügung gestellt. Die aktuelle Version kann unter folgender URL heruntergeladen werden: [https://releases.lernstick.ch](https://releases.lernstick.ch)

Die Dateinamen der ISO-Abbilder folgen immer dem Schema "lernstick_<datum>.iso". Sie können also das neueste Abbild am Datum im Dateinamen erkennen. Im Moment ist das ISO-Abbild ungefähr 18,8 GB groß. Das Herunterladen kann also eine Weile dauern.
